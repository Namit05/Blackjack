# 🃏 Blackjack Game

Description

Feeling lucky? Welcome to Blackjack 🃏
It’s you vs the dealer in a simple but dangerously addictive game of getting as close to 21 as possible. Go too low, you lose. Go too high… you definitely lose 

## Features of the Code

- Random card dealing system  
- Automated dealer logic  
- Smart Ace handling (1 or 11 automatically)  
- Score calculation and comparison  
- Bust detection system  
- Replay option to keep playing  
- Clean user input (Hit / Stand)  
- Displays player and dealer hands clearly  

## Tech Used

- Python (core language)  
- `random` module for card selection  
- Command Line Interface (CLI) for gameplay  

## Rules of the Game

- Get as close to 21 as possible without going over  
- Number cards = value, face cards = 10, Ace = 1 or 11  

### Your Moves:
- Hit → take another card  
- Stand → stop and lock your score  

### What Happens:
- Go over 21 → you lose  
- Dealer plays after you stand (must reach 17)  
- Dealer busts → you win  
- Closest to 21 wins  
- Same score → tie
