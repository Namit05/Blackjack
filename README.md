# 🃏 Blackjack Game

Description

A console-based implementation of the classic Blackjack card game. The player competes against a computer dealer, aiming to reach a hand value of 21 without exceeding it.

## 🚀 Features

* Random card dealing
* Player vs dealer gameplay
* Automatic score calculation
* Win/lose/draw detection
* Simple and interactive CLI interface

## 🛠️ Tech Used

* Python
* CLI (Command Line Interface)

## ▶️ How to Run

```bash
python main.py
```

## 🎮 How to Play

* You are dealt two cards at the start
* Choose whether to "hit" (draw another card) or "stand"
* The dealer draws cards based on predefined rules
* The player closest to 21 (without going over) wins
